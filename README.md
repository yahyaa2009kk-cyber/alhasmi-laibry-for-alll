# مكتبة الهاشمي — النسخة الرسمية

النسخة الرسمية الجاهزة للنشر على Netlify، ومربوطة بمشروع Supabase باستخدام Publishable key فقط.

## المزايا
- الموقع العام RTL بتصميم مكتبة الهاشمي.
- الأقسام: الابتدائي، المتوسط، والإعدادية مع العلمي والأدبي.
- محتوى ديناميكي من Supabase.
- لوحة إدارة على `/admin`.
- تسجيل دخول حقيقي عبر Supabase Auth.
- إضافة وتعديل وحذف المحتوى.
- المرحلة + الفرع + المادة + نوع المحتوى.
- السعر بالدينار العراقي: 0 = مجاني.
- رفع ملفات PDF إلى Storage.
- بحث وتصفية وإحصائيات في لوحة الإدارة.
- رقم التواصل: 07740478255.

## الأمان
لا توجد Secret key داخل المشروع. الكتابة والتعديل والحذف محمية بسياسات RLS وحساب المدير الموجود في `admin_users`.

## النشر
ارفع محتويات هذا المجلد إلى Netlify. لا تفتح `index.html` من مدير الملفات للحكم على الشكل؛ الاختبار الصحيح يكون من رابط Netlify.

## قاعدة البيانات
تم تجهيز جدول `public.content` ليحتوي على `price` و`branch`، مع حماية الإدارة عبر `public.admin_users` حسب إعدادات Supabase التي تم تنفيذها.
